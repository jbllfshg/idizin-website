# Idizin homepage concepts

Five homepage design concepts for [Idizin Sydney](https://www.idizin.com.au/). Open `index.html` in a browser, or open any page in `concepts/` directly. Each page is a single self-contained HTML file.

| # | Concept | File |
|---|---------|------|
| 1 | Editorial | `concepts/1-editorial.html` |
| 2 | Full bleed | `concepts/2-fullbleed.html` |
| 3 | Portfolio grid | `concepts/3-portfolio.html` |
| 4 | Dark luxe | `concepts/4-darkluxe.html` |
| 5 | Swiss typographic | `concepts/5-swiss.html` |

## Notes

- **Signature blue:** every page defines it once as `--blue` at the top of its `<style>` block. It is currently a stand-in (`#1B4D9B`) until the exact brand hex is confirmed.
- **Imagery:** the building illustrations are generated in the browser by a small script at the bottom of each page. They are placeholders for real project photos and renders. Project names are placeholders too.
- **Fonts** load from Google Fonts.
